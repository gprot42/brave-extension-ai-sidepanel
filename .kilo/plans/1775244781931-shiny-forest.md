# Gemini Side Panel - Brave/Chrome Extension for Google Workspaces (Docs)

**Finalized Implementation Plan (2026)**

## Scope & Architecture
- Plasmo framework (best DX for MV3 extensions, auto-reload, easy TS/React).
- Side panel using `chrome.sidePanel` API (opened from toolbar icon).
- Content script injected on `https://docs.google.com/document/*` to extract:
  - Main document text
  - Comments (threads, authors, resolved, highlighted text)
- Background PW (persistent messaging hub).
- Modern chat UI in side panel with:
  - Gemini model selector (2026 IDs).
  - Streaming responses.
  - Token estimation.
  - API key management via `chrome.storage`.
- Docs-first: comments in code, README, clear errors.

## Current Gemini Models (2026)
- `gemini-3.1-flash`: Fast, cost-effective.
- `gemini-3.1-flash-lite`: Ultra-fast variant.
- `gemini-3.1-pro`: Full reasoning power.

Endpoint: `https://generativelanguage.googleapis.com/v1beta/models/{model}:streamGenerateContent`

## Permissions & Best Practices
manifest.json permissions:
```json
"permissions": ["sidePanel", "storage", "activeTab"],
"host_permissions": ["https://docs.google.com/*", "https://drive.google.com/*"],
```
