# Plan to Build: Gemini Side Panel Extension for Google Workspaces

**Target**: Brave/Chrome Manifest V3 extension with a clean right-side panel for Google Docs (MVP), using the official Gemini API.

**Confirmed Preferences**:
- Scope: Google Docs first ("Docs now, others later")
- Tech: Plasmo framework (best DX for MV3 extensions with TypeScript, hot reload, and easy side panel support)

## Architecture Overview

- **Side Panel UI** (Plasmo `sidepanel/`): Modern chat interface with model selector, context refresh, and prompt input.
- **Content Script**: Injected only on `docs.google.com/document/*` — extracts document text + comments using robust, modular selectors (with fallback polling).
- **Background Service Worker** (`background.ts`): Handles `chrome.sidePanel.open()`, message routing, and API key management.
- **Storage**: `chrome.storage.sync` for API key (with validation).
- **API**: Direct calls to `https://generativelanguage.googleapis.com` using latest Gemini models.

## Current Gemini Models (as of April 2026)

- `gemini-3.1-pro-preview` (best quality)
- `gemini-3.1-flash` (fast & cheap)
- `gemini-3-flash` (latest lightweight)

Model selector will map friendly names to these IDs.

## Step-by-Step Implementation Plan

### 1. Project Setup (Plasmo)
- Initialize new Plasmo project or migrate existing structure into Plasmo.
- Configure `manifest.json` via `plasmoconfig.ts`.
- Add required permissions: `"sidePanel"`, `"storage"`, `"activeTab"`.
- Host permissions: `["https://docs.google.com/document/*"]`.

### 2. Side Panel UI
- Create modern chat UI (React + Tailwind recommended in Plasmo).
- Features: model dropdown, "Refresh Context" button, message history, prompt input.
- On open: request document context from content script.

### 3. Content Script (Document Context Extraction)
- Use `MutationObserver` on main editor container.
- Extract:
  - Main document text (concatenated paragraphs).
  - Comments: author, text, resolved status, reply threads.
- Make selectors configurable in a separate constants file for easy updates.
- Debounce updates (800ms).
- Return clean JSON context.

### 4. Background & Messaging
- Open side panel on toolbar icon click (if on supported page).
- Route messages between side panel and content script.
- Secure API key storage and retrieval.

### 5. Gemini API Integration
- Support streaming (`streamGenerateContent`) for better UX.
- Prompt template: document text + comments + user question.
- Add token estimation and context trimming.
- Handle errors, rate limits, and invalid API keys gracefully.

### 6. Polish & Testing
- Material 3 / Google-style UI.
- Loading states, error messages.
- Console debugging helpers.
- Test on real Google Docs with comments.

### 7. Phase 2 (Post-MVP)
- Support for Sheets & Slides.
- Multi-turn chat with persistent context.
- Selection-only "smart context" mode.
- Optional OAuth (Drive/Docs API) for more reliable access.

## Challenges & Mitigations

| Challenge                      | Solution                                      |
|-------------------------------|-----------------------------------------------|
| Google Docs DOM changes       | Modular selectors + config + fallback polling |
| API key security              | `chrome.storage.sync` only, validate format   |
| Large context limits          | Token estimation + optional smart context     |
| Side panel UX                 | Match Google design system                    |
| Browser compatibility         | Target Brave + Chrome, test MV3 compliance   |

- **Polished**: 25–35 hours.
